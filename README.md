# Osteologia

An interactive 3D atlas of the human skeleton for anatomy study. Osteologia renders a complete, stylised skeleton in the browser with Three.js and lets you inspect individual bones, anatomical records, skeletal regions, movement patterns, and clinical notes.

## Features

- Procedurally generated skeleton with 206 named bones; no downloaded mesh files are required.
- Male and female skeletal profiles with different proportions and pelvic/skull morphology.
- Searchable bone atlas with Latin names, descriptions, landmarks, articulations, attachments, ossification, and clinical relevance.
- Axial, appendicular, and all-bones navigation filters.
- Interactive 3D camera controls: orbit, zoom, pan, front, back, lateral, superior, and reset views.
- Anatomical rest, quiet respiration, walking gait, running gait, spinal range of motion, upper-limb range of motion, and temporomandibular-joint animations.
- Play/pause, animation speed, exploded view, cartilage/disc visibility, region labels, ground, and X-ray controls.
- Bone focus and isolation modes.
- Identification quiz with score, streak, and answer feedback.
- Responsive interface designed for desktop and tablet-sized screens.

## Requirements

- Node.js 18 or newer
- A modern browser with WebGL and ES modules support

## Getting Started

Clone or download the repository, then install the Three.js dependency:

```bash
npm install
```

Because the application uses browser modules and imports Three.js from `node_modules`, serve the project over HTTP. For example, using Python:

```bash
python3 -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000) in your browser.

You can use any static file server instead. There is currently no build step or development server configured in `package.json`.

## Controls

### Mouse and pointer

- Drag to orbit the camera.
- Scroll to zoom.
- Right-drag to pan.
- Click a bone in the model or navigator to open its anatomical record.

### Keyboard

| Key | Action |
| --- | --- |
| `/` | Focus the search field |
| `Esc` | Deselect the current bone or close the active overlay |
| `Space` | Play or pause the selected animation |
| `I` | Toggle isolation for the selected bone |
| `F` | Focus the camera on the selected bone |
| `X` | Toggle X-ray mode |
| `1` | Anterior view |
| `2` | Posterior view |
| `3` | Lateral view |
| `4` | Superior view |
| `5` | Reset view |

## Project Structure

```text
.
├── index.html              # Application shell and UI markup
├── css/style.css            # Layout, theme, and responsive styles
├── js/main.js               # Three.js scene, interaction, and UI wiring
├── js/anim.js               # Procedural movement modes and gait curves
├── js/materials.js          # Bone materials and studio environment
├── js/data/bones.js         # Bone records, regions, and clinical notes
└── js/skeleton/              # Procedural skull, axial, and appendicular builders
```

The skeleton is assembled from geometry generated by the modules in `js/skeleton/`. Bone metadata lives separately in `js/data/bones.js`, so anatomy content and rendering logic can be updated independently.

## Development

This is a dependency-light browser project using native JavaScript modules and Three.js. Edit the source files, reload the browser, and watch the browser console for runtime errors. The project does not currently include automated tests or a linting configuration.

## Educational Disclaimer

Osteologia is a visual study aid. The models are stylised and procedurally generated, and the anatomical notes are provided for educational reference. It is not a patient-specific model, diagnostic image, or substitute for clinical training and should not be used for medical decision-making.

## Sources

The in-app reference notes are cross-checked against *Gray's Anatomy* (42nd edition), *Moore's Clinically Oriented Anatomy* (8th edition), *Terminologia Anatomica* (2nd edition), and *Netter's Atlas of Human Anatomy* (7th edition). Gait kinematics follow Winter's *Biomechanics and Motor Control of Human Movement*.
